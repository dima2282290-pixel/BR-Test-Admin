# BR Test Admin v2

Самостоятельный тестовый проект, вдохновлённый мобильными RP-играми.
Не использует официальный клиент, сервер или закрытые ресурсы Black Russia.

Возможности прототипа:
- авторизация игрока;
- админ-роль;
- отдельная админ-панель;
- список игроков;
- kick;
- teleport;
- выдача денег;
- выдача уровня;
- spawn;
- mute;
- broadcast;
- серверный чат;
- JSON-протокол клиент <-> сервер.
